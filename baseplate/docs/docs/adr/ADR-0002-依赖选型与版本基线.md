# ADR-0002 · 依赖选型与版本基线

- 状态：已接受（2026-09-30）
- 复核周期：每季度；升级前先看 CHANGELOG

## 基线（全部实测可从 Maven Central 解析，不是凭记忆写的）

| 依赖 | 版本 | 为什么是这个版本 |
| --- | --- | --- |
| Java | 21 (GraalVM 21.0.5) | LTS；虚拟线程可用于 IO 密集的外部模型调用 |
| Spring Boot | **3.5.16** | 3.5 线的**最新稳定 GA**。注意 `maven-metadata` 里 `<release>` 指向 4.2.0-M2，那是里程碑版，不能用于生产 |
| agentscope-java | **2.0.3** | 用户要求最新版。实测 `io.agentscope:agentscope` 的 latest 就是 2.0.3（2026-09-07 发布） |
| springdoc-openapi | 2.9.1 | 停在 2.x：springdoc 3.x 面向 Boot 4，本项目在 Boot 3.5 线 |
| ArchUnit | 1.5.1 | 架构断言，本项目最重要的一组测试 |
| pgvector JDBC | 0.1.6 | 写 `t_kb_chunk.embedding` 需要注册 vector 类型 |
| Flyway | 11.7.2 | **必须与 Boot 3.5.16 管理的版本一致**，否则找不到 PG 方言实现 |
| jjwt | 0.12.6 | 0.13.x 有 API 变动，暂不跟进 |
| spring-security-crypto | (BOM 管理) | 只引这一个模块拿 BCrypt，不引整套 Spring Security |
| Testcontainers | 1.21.4 | 只引 `postgresql` 与 `junit-jupiter` |

agentscope 三个扩展模块（dashscope / openai / anthropic）与 core 都是 2.0.3，
实测 `maven-metadata` 的 `<latest>` 全部对齐。

## 两个踩过的坑（写下来免得再踩）

1. **`org.testcontainers:redis` 这个构件不存在**（Maven Central 实测 404）。
   第一次构建就是被它拦下来的。已移除；Redis 相关的对抗用例暂无自动化，
   见 `docs/06-测试与验收.md` 的未覆盖清单。
2. **`~/.m2` 在本机沙箱下不可写**（`AccessDeniedException` on `.lastUpdated`）。
   构建命令因此带上 `-Dmaven.repo.local=.mvn-repo`，仓库放在工程内（已 gitignore）。
   这不是项目要求，是本机的临时约束，环境恢复后可以去掉。

## 明确不引入的东西

| 不引入 | 理由（不是「以后再说」，是不需要） |
| --- | --- |
| Elasticsearch | 单村可检索文档量是千级，PG + pg_trgm 够用，运维成本远超收益 |
| Kafka / RocketMQ | 生产者与消费者同库同进程，一张 `t_event` 表就有「至少一次」投递 |
| K8s | 与既有部署栈（Docker + Jenkins）一致，村级单机规模用不上 |
| Lombok | 用 Java record 承载 DTO，不需要 getter/setter 生成 |
| JPA | 见 ADR-0004 |
| LangChain4j 之类 | 见 ADR-0001（已改为用 agentscope-java） |
