# 03 · 接口清单

## 通用约定

| 项 | 约定 |
| --- | --- |
| 路径前缀 | 小程序 `/api/mp/**`、后台 `/api/admin/**`、AI `/api/ai/**`、公共 `/api/auth/**` `/api/common/**` |
| 响应 | `{code, msg, data, traceId}`；分页 `{list, total, page, size}`。`code=0` 成功 |
| HTTP 状态码 | **仍然要正确**（400/401/403/404/429/500）。全 200 靠 code 区分会让网关与监控失去判断依据 |
| 时间 | ISO-8601 带时区，不返回「2 小时前」——那是前端的事，且进缓存会出错 |
| 分页 | `page` 从 1 起，`size` 默认 20 上限 100 |
| 幂等 | 写接口接受 `Idempotency-Key` 头 |
| 鉴权 | `Authorization: Bearer {jwt}`，载荷含 uid / villageId / roles / scope |
| traceId | 任何响应都带。用户报「这步错了」时靠它定位 |
